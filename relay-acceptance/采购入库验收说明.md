# 采购入库验收说明

验收标识 **JSH-RELAY-BASELINE**

这份资料用于 Relay 的使用前验收。它记录独立验收分支的状态，业务对象来自 jshERP 的采购入库流程。

## 当前代码

采购入库新增沿用 `POST /depotHead/addDepotHeadAndDetail`。入口在 `jshERP-boot/src/main/java/com/jsh/erp/controller/DepotHeadController.java`，由 `DepotHeadService.addDepotHeadAndDetail` 完成保存。

当前分支尚未提供采购入库预检接口。预检功能的需求是独立检查供应商与结算账户，且不写入入库单。

## 验收条件

1. 后端声明 `POST /depotHead/purchasePreflight` 接口。
2. 供应商缺失或 ID 无效时，返回「请选择供应商」。
3. 结算账户缺失或 ID 无效时，返回「请选择结算账户」。
4. 新增针对预检接口的自动化测试。

验收应分别核对接口实现、源码引用和自动化测试。源码评估可确认代码中存在的条件，实际接口运行需要单独验证。
